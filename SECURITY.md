# Security Policy / Güvenlik Politikası

## 🌐 English

### Supported Versions
**OpenVetAtlas Android (oVa)** is a standalone offline 3D educational application for Android smartphones and tablets. It does not collect, store, or transmit personal user data, credentials, or telemetry over the network, and requires zero internet or device permissions.

| Version | Supported |
| :--- | :--- |
| `v0.4.x-beta` / `v1.0.x` (Latest) | :white_check_mark: Yes |
| `< v0.4.0` | :x: No |

### Reporting a Vulnerability or Issue
If you discover a security vulnerability, crash, or critical bug within the software architecture or build pipeline:
1. Please use GitHub's **[Private Vulnerability Reporting](https://github.com/eoyavas/OpenVetAtlas-Android/security/advisories/new)** feature under the **Security** tab, or open an issue on the repository.
2. Include steps to reproduce the issue, the Godot Engine version (`4.3+`), and the target Android device model / OS version.

## 🇹🇷 Türkçe

### Desteklenen Sürümler
**OpenVetAtlas Android (oVa)**, Android telefon ve tabletler üzerinde tamamen çevrimdışı (*offline*) olarak çalışan üç boyutlu bir veteriner anatomi eğitim uygulamasıdır. Uygulama hiçbir kişisel veriyi, kullanıcı bilgisini veya ağ telemetrisini toplamaz, dış sunuculara iletmez ve herhangi bir cihaz izni talep etmez.

| Sürüm | Destek Durumu |
| :--- | :--- |
| `v0.4.x-beta` / `v1.0.x` (Güncel) | :white_check_mark: Destekleniyor |
| `< v0.4.0` | :x: Desteklenmiyor |

### Güvenlik Bildirimi ve Hata Raporlama
Yazılım mimarisinde veya derleme yapısında bir güvenlik açığı ya da kritik bir hata tespit ederseniz:
1. GitHub üzerindeki **Security** sekmesinde yer alan **[Private Vulnerability Reporting](https://github.com/eoyavas/OpenVetAtlas-Android/security/advisories/new)** bağlantısını kullanabilir veya depo üzerinde bir kayıt (*Issue*) açabilirsiniz.
2. Bildiriminizde hatanın nasıl tekrarlandığını, kullanılan Godot sürümünü (`4.3+`) ve Android telefon/tablet modelini belirtmeniz incelenmesini hızlandıracaktır.
